# fuckssj

fuckssj 是一个本地优先的记账 App，用来继续使用已有的随手记本地备份数据，并在一个轻量、直接、可控的应用里管理账本。

## 当前能力

- 多账本管理：创建空白账本、导入账本、打开已有账本、重命名、备注、导出和删除。
- 随手记备份导入：支持从随手记本地备份导出的 `.kbf` 文件创建账本。
- SQLite 导入：支持导入 `.sqlite`、`.sqlite3`、`.db`、`.db3` 文件。
- 首页看板：显示今天、本周、本月、本年收入和支出；外币流水会按本地汇率缓存折算为人民币后汇总。
- 流水查询：按日期、账户、币种、分类、收入/支出、金额范围和备注关键词筛选。
- 查询汇总：查询结果页提供可展开的汇总表，列出所有非零汇总项；汇总内容较长时可在面板内滚动查看。
- 查询分页：查询结果按页显示，每页 30 条流水；底部提供首页、上一页、页码输入、下一页、尾页。
- 流水编辑：新建、编辑、删除收入和支出记录。
- 分类管理：每个账本维护自己的收入/支出分类，支持一级分类和二级分类。
- 账户管理：每个账本维护自己的账户组和账户，按两级结构显示和选择。
- 外币管理：每个账本维护自己的常用币种列表，显示本地缓存汇率。
- 主题与字号：支持浅色、深色、跟随系统，并提供字号加大选项。

## 安装

### Android

项目不计划发布到 Google Play 或其它应用商店。正式 APK 通过 GitHub Releases 分发。

1. 打开本仓库的 GitHub Releases 页面。
2. 下载最新版本的 Android APK 文件。
3. 在 Android 手机上打开 APK 文件并安装。
4. 如果系统提示禁止安装未知来源应用，需要先为当前文件管理器或浏览器允许“安装未知应用”。

升级安装时，Android 会校验应用签名。使用同一签名发布的新版本可以覆盖安装，并保留已有 App 数据。

### iOS

iOS 版本使用同一套账本数据规则和本地存储逻辑。正式安装方式以 GitHub Releases 或发布说明为准。

iOS 对文件访问采用系统文件选择器和 App 沙盒机制：导入账本后，App 会把文件复制到自己的管理目录；导出账本时，需要选择系统允许写入的位置。

## 数据与隐私

- 账本文件保存在本机，App 不提供云同步。
- 一个账本对应一个由 App 管理的 SQLite 文件。
- 从外部导入账本时，App 会复制文件到自己的管理目录；导入完成后不依赖原始文件路径。
- 导出账本会得到明文 SQLite 文件，请自行妥善保存。
- 当前版本不包含密码、生物识别、数据库加密或远程备份能力。
- 删除账本会删除 App 管理目录中的账本文件、配置文件和索引记录，请在删除前确认已经备份。
- 删除分类或账户时，如果该分类或账户下已经有流水，相关流水也会一起删除，App 会在删除前提示确认。

## 从随手记迁移

推荐直接在 App 首页使用“从随手记本地备份导出的 KBF 文件创建”。

随手记本地备份通常可以通过以下流程生成：

1. 在随手记 App 中进入账本主页右下角设置。
2. 进入高级功能、备份与同步、本地备份与恢复。
3. 执行立即手动备份，得到 `.kbf` 文件。
4. 在 fuckssj 中选择该 `.kbf` 文件导入。

`.kbf` 文件本质上是压缩包，里面包含账本数据库。fuckssj 会在 App 内完成解包、恢复、校验和导入流程。
