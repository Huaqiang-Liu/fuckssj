# App 使用流程

本文说明当前版本的页面结构、主要操作和可见行为。

## 整体导航

App 分为“首页”和“账本内页”。

首页用于选择、创建、导入、导出和管理账本。打开某个账本后进入账本内页；如果要切换账本，需要先从账本内页返回首页。

App 启动时会尝试打开上次使用的账本。如果上次账本仍然存在，会直接进入该账本；如果没有上次账本、账本文件不存在或账本索引不可用，会进入首页。

主题和字号设置从某个账本的设置页进入，但设置结果对整个 App 生效。分类、账户和常用币种只属于当前账本。

## 首页

首页顶部标题为“账本”。如果没有任何账本，页面会显示空状态和创建入口；如果已有账本，页面会显示账本列表和创建入口。

首页可以进行以下操作：

- 打开已有账本。
- 创建空白账本。
- 从 SQLite 文件创建账本。
- 从随手记本地备份导出的 KBF 文件创建账本。
- 重命名账本。
- 编辑账本备注。
- 导出账本。
- 删除账本。

账本名称不能为空，不能超过长度限制，不能包含文件名非法字符，并且不能和已有账本重名。

删除账本会删除 App 管理的账本文件、配置文件和索引记录。删除前请先确认已经备份。

## 导入账本

从 SQLite 创建账本时，可以选择 `.sqlite`、`.sqlite3`、`.db`、`.db3` 文件。

从随手记本地备份创建账本时，可以选择 `.kbf` 文件。App 会在本地完成解包、恢复、校验和导入。

导入成功后，App 使用自己的账本副本，不再依赖原始文件路径。

## 账本内页

账本内页只显示当前账本的数据和操作入口。

页面主要区域包括：

- 顶部标题：显示当前账本名称，左上角返回首页。
- 看板区：显示今天、本周、本月、本年收入和支出。
- 查询区：选择筛选条件并进入查询结果页。
- 底部操作：新建流水和进入设置页。

## 首页看板

四个看板分别显示今天、本周、本月、本年的收入和支出合计。

收入金额显示为红色，支出金额显示为绿色。人民币流水直接计入统计；外币流水会按本地汇率缓存折算为人民币后计入统计。汇率缓存刷新失败时，会继续使用已有缓存，不影响打开账本和记账。

看板数据可以在后台计算。看板尚未加载完成时，不应阻塞查询、新建流水或进入设置页。

## 查询筛选

查询区支持以下筛选条件：

- 账户。
- 开始日期和结束日期。
- 币种。
- 分类。
- 金额范围。
- 收入和支出方向。
- 备注关键词。

默认筛选规则是账户全选、时间全选、币种全选、分类全选、收入和支出全选、金额范围为空、备注关键词为空。

账户筛选使用当前账本设置中的账户列表，而不是只使用已经出现在流水里的账户。账户按“账户组 -> 账户”的两级结构显示；勾选账户组会勾选该组下的全部账户，取消其中任意账户后，该账户组不再视为全选。

分类筛选按一级分类和二级分类显示。收入分类和支出分类可以分别全选，方便只筛选收入、只筛选支出，或筛选部分分类。

金额范围两个输入框分别表示最低金额和最高金额。两个都为空表示不限制金额；只填最低金额表示大于等于该金额；只填最高金额表示小于等于该金额。

备注关键词为空时不限制备注。填写关键词时，会按备注文字进行匹配。

点击“重置筛选规则”会恢复默认筛选。

## 查询结果页

查询结果页展示当前筛选条件下的流水，不在该页面修改筛选条件。需要调整筛选时，返回账本内页修改。

页面顶部会显示查询到的流水总数和当前页码。列表按时间从新到旧排列，同一天的流水归在同一个日期标题下。点击日期标题可以折叠或展开当天流水。

点击流水条目会进入流水编辑页。

## 查询汇总

查询结果页提供可展开的汇总表。汇总会覆盖当前筛选范围内的全部流水，而不是只统计当前页。

汇总表会列出所有非零汇总项。内容较长时，展开区域会在面板内滚动，避免挤出屏幕。

汇总加载和流水列表加载相互独立。汇总尚未完成时，可以先查看当前页流水。

## 查询分页

查询结果每页显示 30 条流水。底部只保留一行分页控件：

- 首页。
- 上一页。
- 居中的页码输入框。
- 下一页。
- 尾页。

页码输入框用于跳转到指定页。当前页、总页数和流水总数显示在页面顶部，不在底部重复显示。

翻页或跳页时，App 只加载目标页需要显示的流水。

## 流水编辑页

流水编辑页同时用于新建、查看和编辑流水。

可以填写或修改：

- 收入或支出方向。
- 金额。
- 币种。
- 分类。
- 账户。
- 记账时间。
- 文字备注。

新建流水时会自动聚焦金额输入框，方便直接输入数字。保存时会校验金额、分类、账户、币种和时间。

编辑已有流水时，可以保存修改，也可以删除流水。删除前会弹出确认提示。

## 分类选择与分类管理

分类分为支出分类和收入分类。每一类都按“一级分类 -> 二级分类”的两级结构显示。

分类管理可以新增、重命名和删除分类。一级分类不能和同方向下的其它一级分类重名；同一个一级分类下的二级分类不能重名。

删除分类时，如果该分类下已经有流水，相关流水也会一起删除。App 会在删除前提示确认。

重命名分类后，历史流水会显示新的分类名称。

## 账户选择与账户管理

账户按“账户组 -> 账户”的两级结构显示。默认账本模板也使用这种两级结构。

账户管理可以新增账户组、新增账户、重命名和删除。账户名称在当前账本内不能重复。

删除账户组会删除该组下的账户；如果这些账户已经被流水使用，相关流水也会一起删除。删除单个账户时同理。App 会在删除前提示确认。

重命名账户或账户组后，历史流水会显示新的账户名称。

## 币种与汇率

每个账本有自己的常用币种列表。人民币默认可用；其它币种可以在外币管理页添加或移除。

外币管理页显示当前常用币种和本地缓存汇率。删除常用币种只会把该币种移出当前账本的常用列表，不会删除已经存在的历史流水。

看板和查询汇总需要折算外币时，会使用本地汇率缓存。缓存刷新失败时，App 会继续使用已有缓存。

## 账本设置页

账本设置页用于查看和修改当前账本信息，并进入各类管理页面。

可以进行以下操作：

- 修改账本名称。
- 修改账本备注。
- 切换主题：浅色、深色、跟随系统。
- 调整字号加大选项。
- 进入分类管理。
- 进入账户管理。
- 进入外币管理。

主题和字号设置对所有账本生效；账本名称、备注、分类、账户和常用币种只作用于当前账本。
