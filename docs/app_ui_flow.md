# App 界面与跳转设计草稿

本文档描述 Flutter 记账 App 的界面结构、每个界面包含的内容、可打开的弹窗、按钮行为和跳转目标。后续编码以本文档审阅后的版本为准；如果实现与本文档冲突，优先修改实现，而不是让实现继续漂移。

## 设计目标

这部分是总纲领，下面的表述如果有与这部分冲突的，以这里为准。
1. 导入和导出账本，多账本命名、管理、备注。一个账本是一个 .sqlite 文件。
2. 设置界面包含调节浅色/深色/跟随系统。
3. 记账，每条记账涉及：一级二级分类，收入和支出（金额默认人民币，可以修改成外币，可以在记账界面选择外币列表时跳转，或在主设置编辑常用外币以显示在列表，后续可以现场查询汇率，==注意：原版随手记不支持外币记录，可能需要增补数据库格式，即在导入外部数据库文件后可能需要修改==），记账时间，账目备注（文字和图片），金额计算器，一级二级所属账户（现金、信用卡、金融账户（银行卡/股票/基金）、虚拟账户（支付宝/微信/白条/公交卡/饭卡）、负债账户（应付款项）、债券账户（应收款项）
4. 查询和编辑账目，【编辑和新建是同一个界面】，查询时每个账户一个列表。可以筛选日期（几种方式：全部/自定义x年x月x日~y年y月y日/某年/某月/某星期），筛选分类，筛选支出或收入（或者都有）。可以搜索关键字（匹配分类和备注，严格匹配，字段可以留空但不能全空）
5. 自定义一级二级分类、一级二级所属账户、显示外币种类（设置时加上搜索）。分类用JSON文件维护（key-value+列表的模式很方便）。删除分类前要提示：删除分类也会删除其下流水，等待3秒后点击确认才能删除。分类不可重名，但是不同一级分类下的二级分类可以重名，去重时同时考虑一级和二级分类。修改分类名称后，涉及条目也自动修改。可以从记账/编辑界面跳转，也可以从主设置访问。
6. 安全性约束。账本默认明文存储在本地，但如果用户在设置中要求添加保护，可以添加密码/人脸/指纹，每次关闭后台都要重新验证，否则本地存储的所有账本文件将会加密——但是已经导出的文件不会加密（这点需要在加密设置界面提醒用户，另外加密的账本导出时需要验证）。加密的密码学方式暂时不确定，要防止密钥明文存储在本地。

## 全局导航原则

App 的一级导航分为“首页”和“账本内页”。首页负责选择、创建、导入和管理账本；账本内页负责查看和操作某一个已经打开的账本。进入某一账本后，不再显示三种创建账本入口，也不在右上角通过菜单切换账本；必须先返回首页，才能看到创建入口和账本选择列表。

App 启动时读取本地持久化状态。如果存在上次打开的账本，并且对应账本文件仍存在，默认直接进入该账本的账本内页；如果没有上次账本、账本文件丢失、账本索引损坏或首次启动，则进入首页。账本内页左上角返回按钮回到首页；首页可以重新打开任意已有账本。如果每次默认打开账本的时候，有自动跳转（而不是直接初始化到账本界面），则需要添加开屏界面（随便放点什么即可）。

账本文件和账本索引均由 App 管理。账本索引用于保存账本名称、文件路径、来源、创建时间、上次打开账本等元信息。账本名称由用户手动填写，不能为空，不能超过 40 个字符，不能包含 `\ / : * ? " < > |`，并且和现有账本大小写不敏感地查重。用户在首页可以修改账本名称。

## 首页

首页是账本选择和账本创建入口，不展示某个账本的流水列表。首页顶部标题为 `账本`。如果没有任何账本，页面主体显示空状态文案和三个创建入口；如果已有账本，页面主体先显示账本列表，再显示创建入口。

首页内容：

- 顶部 AppBar：标题 `账本`。
- 已有账本列表：每个条目显示账本名称、来源类型、创建时间或最近打开时间、可选备注、文件状态。
- 创建入口区：三个按钮分别为 `创建空白账本`、`从 SQLite 创建`、`从 KBF 创建`。
- 状态提示区：导入中、创建中、导入失败、账本文件丢失等错误或进度信息。

首页按钮与跳转：

- 点击已有账本条目：设置该账本为上次打开账本，打开账本内页。
- 点击 `创建空白账本`：打开命名账本弹窗；命名成功后创建空白 SQLite 账本，写入 App schema 增广表，注册账本索引，进入账本内页。
- 点击 `从 SQLite 创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.sqlite`、`.sqlite3`、`.db`、`.db3`；选择成功后复制文件到 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。
- 点击 `从 KBF 创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.kbf`；选择成功后在 Dart 侧解析 ZIP，读取 `mymoney.sqlite`，恢复 SQLite 头，校验数据库，写入 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。

首页后续可增加的账本管理动作：

- 长按账本条目或点击条目右侧更多按钮：打开账本操作菜单。
- 账本操作菜单包含 `重命名`、`编辑备注`、`导出账本`、`删除账本`。
- `删除账本` 必须弹出确认弹窗，提示会删除 App 管理目录中的账本副本；如果未来实现“仅从列表移除但保留文件”，需要单独提供清晰选项。

## 命名账本弹窗

命名账本弹窗由首页的三个创建入口触发。弹窗不负责实际创建或导入文件，只负责收集和校验账本名称。

弹窗内容：

- 标题：`命名账本`。
- 输入框：标签 `账本名称`，最大长度 40。
- 错误提示：显示名称为空、名称过长、包含非法字符、名称已存在等错误。
- 按钮：`取消`、`继续`。

弹窗行为：

- 点击 `取消`：关闭弹窗，停留首页，不继续文件选择或创建账本。
- 点击 `继续`：校验账本名称；校验失败时留在弹窗并显示错误；校验成功时关闭弹窗，把名称返回给首页的对应流程。
- 输入法完成键：等同点击 `继续`。

## 文件选择器

文件选择器由首页的导入流程触发，不是 App 自绘页面。文件选择器关闭后，回到首页对应流程继续处理。

SQLite 文件选择：

- 允许扩展名：`.sqlite`、`.sqlite3`、`.db`、`.db3`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：复制到 App 管理目录，不长期依赖原文件路径。

KBF 文件选择：

- 允许扩展名：`.kbf`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：Dart 侧执行和 Python 脚本等价的恢复逻辑；Python 脚本仍保留给桌面手动恢复使用。

## 账本内页

账本内页只展示当前打开账本的数据和操作入口。账本内页不显示三种创建账本入口，也不在右上角切换账本；账本切换必须返回首页完成。

账本内页内容：

- 顶部 AppBar：左侧返回按钮，标题为当前账本名称，右侧可放 `搜索`、`筛选`、`账本设置` 等动作。
- 概览区：当前筛选范围内的收入、支出、结余或本月摘要，当前阶段可先不实现完整统计。
- 流水列表：按时间倒序显示流水，条目显示分类路径、时间、金额、收入/支出方向、备注摘要。
- 浮动按钮或底部主按钮：`记一笔`。
- 空状态：如果账本没有流水，显示 `暂无流水`，并提供 `记一笔` 入口。

账本内页按钮与跳转：

- 点击左上角返回：回到首页。
- 点击 `记一笔`：进入流水编辑页，模式为新建。
- 点击流水条目：进入流水详情页。
- 点击搜索图标：打开搜索输入，或进入筛选搜索页面。
- 点击筛选图标：打开筛选搜索弹窗或页面。
- 点击账本设置图标：进入账本设置页。

账本内页启动行为：

- App 冷启动时，如果存在可用的上次打开账本，直接进入该页。
- 从首页打开账本时，设置该账本为上次打开账本。
- 如果账本文件丢失，不能进入该页，应回到首页并显示账本文件丢失提示。

## 筛选搜索弹窗或页面

筛选搜索用于控制账本内页的流水列表，不负责跨账本搜索。当前可以先做弹窗，后续复杂后再升级为独立页面。

内容：

- 日期范围：全部、自定义起止日期、某年、某月、某星期。
- 方向：全部、收入、支出。
- 分类：一级分类、二级分类。
- 关键字：匹配分类名称和备注。关键字可以为空，但如果所有筛选条件都为空，应等同无筛选。
- 操作按钮：`重置`、`应用`。

跳转与行为：

- 点击 `应用`：关闭弹窗，账本内页刷新流水列表。
- 点击 `重置`：清空筛选条件，保持弹窗打开。
- 点击弹窗外或返回：关闭弹窗，不应用未保存修改。

## 流水详情页

流水详情页展示一条流水的完整信息。当前从随手记导入的数据可先只读展示，等 App 自有业务表稳定后再支持编辑导入流水。

内容：

- 顶部 AppBar：标题 `流水详情`，返回按钮，右侧 `编辑`。
- 基本信息：收入/支出、金额、币种、记账时间、一级/二级分类。
- 账户信息：付款账户、收款账户，当前可暂不实现。
- 备注：文字备注。
- 附件：图片或文件附件，当前可暂不实现。
- 元信息：创建时间、修改时间、来源标识，调试阶段可显示。

按钮与跳转：

- 点击返回：回到账本内页。
- 点击 `编辑`：进入流水编辑页，模式为编辑。
- 点击 `删除`：打开删除确认弹窗；确认后删除流水并回到账本内页。

## 流水编辑页

流水编辑页同时服务新建和编辑。新建时从账本内页 `记一笔` 进入；编辑时从流水详情页进入。

内容：

- 顶部 AppBar：标题 `记一笔` 或 `编辑流水`，左侧取消/返回，右侧保存。
- 方向选择：收入、支出。
- 金额输入：数字键盘或计算器，默认 CNY。
- 币种选择：默认人民币；后续支持常用外币。
- 分类选择：一级分类、二级分类。
- 账户选择：付款账户或收款账户。
- 时间选择：默认当前时间。
- 备注输入：文字备注。
- 附件入口：后续实现。

按钮与跳转：

- 点击保存：校验金额、分类、账户等必要字段；保存成功后返回账本内页或流水详情页。
- 点击取消/返回：如果有未保存修改，弹出放弃修改确认；否则直接返回来源页。
- 点击分类：打开分类选择页或弹窗。
- 点击账户：打开账户选择页或弹窗。
- 点击币种：打开币种选择页或弹窗。
- 点击时间：打开日期时间选择器。

## 分类选择页或弹窗

分类选择由流水编辑页触发。当前可先实现为弹窗，后续分类管理复杂后再拆为页面。

内容：

- 方向相关的分类列表：支出分类或收入分类。
- 一级分类列表。
- 选中一级分类后显示二级分类。
- 搜索框。
- `新建分类` 入口。

跳转与行为：

- 点击二级分类：返回流水编辑页并填入分类。
- 点击一级分类且没有二级分类：可直接选择一级分类。
- 点击 `新建分类`：进入分类管理页或打开新建分类弹窗。

## 账本设置页

账本设置页只作用于当前账本，不负责切换账本。它从账本内页进入。

内容：

- 账本名称。
- 账本备注。
- 账本文件路径或存储位置说明。
- 来源类型：空白账本、SQLite 导入、KBF 导入。
- 导出账本入口。
- 删除账本入口。
- 后续安全设置入口：密码、生物识别、文件加密。

按钮与跳转：

- 点击保存：保存账本名称和备注，返回账本内页。
- 点击导出：打开系统保存位置选择或分享面板。
- 点击删除：打开删除确认弹窗；确认后删除账本，回到首页。
- 点击安全设置：进入安全设置页，当前阶段暂不实现。

## 需要立刻调整的当前实现

当前实现和本文档不一致的地方：进入某一账本后仍在页面上显示三个创建账本入口，并且右上角可以选择账本。应调整为：创建入口和账本选择只在首页；账本内页只展示当前账本，左上角返回首页。

建议下一轮编码先做导航结构调整，不急着继续添加记账编辑功能。最小改动目标是：建立 `HomePage` 和 `LedgerPage` 两个明确页面；App 启动时按上次账本决定初始页面；从 `LedgerPage` 返回 `HomePage`；创建/导入成功后进入 `LedgerPage`。
