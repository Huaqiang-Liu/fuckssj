# App 界面与跳转设计草稿

本文档描述 Flutter 记账 App 的界面结构、每个界面包含的内容、可打开的弹窗、按钮行为和跳转目标。后续编码以本文档审阅后的版本为准；如果实现与本文档冲突，优先修改实现，而不是让实现继续漂移。

## 设计目标

这部分是总纲领，下面的表述如果有与这部分冲突的，以这里为准。

1. 导入和导出账本，多账本命名、管理、备注。一个账本是一个 `.sqlite` 文件。
2. 设置界面包含调节浅色/深色/跟随系统。
3. 记账，每条记账涉及：一级二级分类，收入和支出（金额默认人民币，可以修改成外币，可以在记账界面选择外币列表时跳转，或在主设置编辑常用外币以显示在列表，后续可以现场查询汇率，==注意：原版随手记不支持外币记录，可能需要增补数据库格式，即在导入外部数据库文件后可能需要修改==），记账时间，账目备注（文字和图片），金额计算器，一级二级所属账户（现金、信用卡、金融账户（银行卡/股票/基金）、虚拟账户（支付宝/微信/白条/公交卡/饭卡）、负债账户（应付款项）、债券账户（应收款项）
4. 查询和编辑账目，【编辑和新建是同一个界面】。可以筛选日期，筛选分类（一级二级，币种，账户），筛选支出或收入（或者都有），筛选金额范围（都留空则全选，只空最低或最高金额则单方向查找即可）。可以搜索关键字（匹配备注文字，严格匹配，默认留空）
5. 自定义一级二级分类、一级二级所属账户、显示外币种类（设置时加上搜索）。分类、账户、外币用 JSON 文件维护（key-value+列表的模式很方便）。删除分类/账户/外币前要提示：删除分类/账户/外币也会删除其下流水，等待 3 秒后点击确认才能删除。分类/账户不可重名，但是不同一级分类下的二级分类可以重名，所以查重时同时考虑一级和二级分类。修改分类/账户名称后，涉及条目也自动修改。可以从记账/编辑界面跳转，也可以从主设置访问。
6. 安全性约束。账本默认明文存储在本地，但如果用户在设置中要求添加保护，可以添加密码/人脸/指纹，每次关闭后台都要重新验证，否则本地存储的所有账本文件将会加密——但是已经导出的文件不会加密（这点需要在加密设置界面提醒用户，另外加密的账本导出时需要验证）。加密的密码学方式暂时不确定，要防止密钥明文存储在本地。
7. 所有金额用 float64 存储，但是显示时保留两位小数。其实只要计算汇率时保留 2 位小数（如 89.64 人民币≈13.19 美元），就不会有涉及更高精度的情况。

## 全局导航原则

App 的一级导航分为“首页”和“账本内页”。首页负责选择、创建、导入、导出和管理账本；账本内页负责查看和操作某一个已经打开的账本。进入某一账本后，不再显示三种创建账本入口，也不在右上角通过菜单切换账本；必须先返回首页，才能看到创建入口和账本选择列表。

App 启动时读取本地持久化状态。如果存在上次打开的账本，并且对应账本文件仍存在，默认直接进入该账本的账本内页；如果没有上次账本、账本文件丢失、账本索引损坏或首次启动，则进入首页。账本内页左上角返回按钮回到首页；首页可以重新打开任意已有账本。如果默认打开账本时存在肉眼可见的自动跳转，而不是直接初始化到账本内页，则需要添加开屏界面。

账本文件和账本索引均由 App 管理。账本索引用于保存账本名称、文件路径、来源、创建时间、最近打开时间、备注、上次打开账本等元信息。账本名称由用户手动填写，不能为空，不能超过 40 个字符，不能包含 `\ / : * ? " < > |`，并且和现有账本大小写不敏感地查重。用户在首页可以修改账本名称。

## 首页

首页是账本选择和账本创建入口，不展示某个账本的流水列表。首页顶部标题为 `账本`。如果没有任何账本，页面主体显示空状态文案和三个创建入口；如果已有账本，页面主体先显示账本列表，再显示创建入口。

首页内容：

- 顶部 AppBar：标题 `账本`，右侧 `主设置` 图标。
- 已有账本列表：每个条目显示账本名称、来源类型、创建时间、最近打开时间、可选备注、文件状态。
- 创建入口区：三个按钮分别为 `创建空白账本`、`从 SQLite 创建`、`从 KBF 创建`。
- 状态提示区：导入中、创建中、导入失败、账本文件丢失等错误或进度信息。

首页按钮与跳转：

- 点击已有账本条目：设置该账本为上次打开账本，打开账本内页。
- 点击 `创建空白账本`：打开命名账本弹窗；命名成功后创建空白 SQLite 账本，写入 App schema 增广表，注册账本索引，进入账本内页。
- 点击 `从 SQLite 创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.sqlite`、`.sqlite3`、`.db`、`.db3`；选择成功后复制文件到 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。
- 点击 `从 KBF 创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.kbf`；选择成功后在 Dart 侧解析 ZIP，读取 `mymoney.sqlite`，恢复 SQLite 头，校验数据库，写入 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。
- 点击主设置图标：进入主设置页。

首页账本管理动作：

- 长按账本条目或点击条目右侧更多按钮：打开账本操作菜单。
- 账本操作菜单包含 `重命名`、`编辑备注`、`导出账本`、`删除账本`。
- `重命名` 使用命名账本弹窗的同一套校验规则。
- `编辑备注` 打开账本备注弹窗，备注可以为空。
- `导出账本` 如果账本未加密，直接进入系统分享或保存入口；如果账本已加密，先要求验证。
- `删除账本` 必须弹出确认弹窗，提示会删除 App 管理目录中的账本文件和索引记录。

## 命名账本弹窗

命名账本弹窗由首页的三个创建入口和账本重命名动作触发。弹窗不负责实际创建或导入文件，只负责收集和校验账本名称。

弹窗内容：

- 标题：新建时为 `命名账本`，重命名时为 `重命名账本`。
- 输入框：标签 `账本名称`，最大长度 40。
- 错误提示：显示名称为空、名称过长、包含非法字符、名称已存在等错误。
- 按钮：`取消`、`继续` 或 `保存`。

弹窗行为：

- 点击 `取消`：关闭弹窗，停留来源页，不继续文件选择或创建账本。
- 点击 `继续` 或 `保存`：校验账本名称；校验失败时留在弹窗并显示错误；校验成功时关闭弹窗，把名称返回给来源流程。
- 输入法完成键：等同点击确认按钮。

## 文件选择器

文件选择器由首页的导入流程触发，不是 App 自绘页面。文件选择器关闭后，回到首页对应流程继续处理。

SQLite 文件选择：

- 允许扩展名：`.sqlite`、`.sqlite3`、`.db`、`.db3`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：复制到 App 管理目录，不长期依赖原文件路径。

KBF 文件选择：

- 允许扩展名：`.kbf`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：Dart 侧执行和 Python 脚本等价的恢复逻辑；Python 脚本仍保留给桌面手动恢复使用。

## 账本内页

账本内页只展示当前打开账本的数据和操作入口。账本内页不显示三种创建账本入口，也不在右上角切换账本；账本切换必须返回首页完成。

账本内页布局：

- 顶部 AppBar：左侧返回箭头，标题显示当前账本名称。
- 顶部看板区：四个看板分别为 `今天`、`本周`、`本月`、`本年`，只展示，不可点击。
- 中部筛选/搜索块：账户、开始时间、结束时间、币种、分类、金额范围、收入/支出、查询备注、查询按钮、重置筛选规则按钮。
- 底部操作区：底部中间放 `新建` 按钮，底部右侧放 `设置` 按钮。

四个看板：

- `今天`：显示最近一笔的二级分类名称、今日总收入、今日总支出。
- `本周`：显示本周一日期到本周日日期、本周总收入、本周总支出。
- `本月`：显示本月一日到本月末日、本月总收入、本月总支出。
- `本年`：显示年份、本年总收入、本年总支出。
- 收入金额显示红色，支出金额显示绿色。
- 如果流水中有外币，看板金额需要按当前汇率折算成人民币后汇总；后续需要定期刷新汇率并重新计算。

筛选/搜索块：

- 点击 `查询`：按当前筛选规则进入流水列表页。查询前检查账户、币种、分类、收入/支出不能全部留空；金额范围如果最小值大于最大值，弹窗提示并留在账本内页。
- 点击 `重置筛选规则`：重置为默认规则。默认规则是账户全选、时间全选、币种全选、分类全选、收入/支出全选、金额范围为空、查询备注为空。
- 每个账本保存上次查询的筛选规则作为账本元数据；再次打开账本时恢复该规则。

筛选字段：

- 账户：点击后打开居中的账户列表复选框弹窗。账户按一级/二级层级展示，用缩进表示，可折叠一级。选中一级账户则二级账户全选；取消任意二级账户后，一级账户的全选状态取消。弹窗内有全选按钮，默认全选。选择后点击确定关闭弹窗。
- 开始时间和结束时间：点击后打开居中的日历弹窗。可以前后切换月份和年份，点击日期选中，点击确定关闭。时间全选默认开启；全选开启时，打开日历仍定位在当前日期所在月份，不定位到 1970 年。选择开始或结束日期后，全选自动取消。
- 币种：点击后打开居中的常用币种复选框弹窗。币种来自主设置里的常用外币列表，默认含人民币。弹窗内有全选按钮，默认全选。取消任意币种后，全选自动取消。
- 分类：点击后打开居中的分类列表复选框弹窗。分类按一级/二级层级展示，用缩进表示，可折叠一级。选中一级分类则二级分类全选；取消任意二级分类后，一级分类的全选状态取消。弹窗内有全选按钮，默认全选。
- 金额范围：两个输入框，分别为最低金额和最高金额。都为空表示全范围；只填最低表示大于等于该金额；只填最高表示小于等于该金额；都填时必须保证最低金额不大于最高金额。
- 收入/支出：两个复选框直接放在筛选块里，不打开弹窗，默认全选。
- 查询备注：文本输入框，默认留空，严格匹配备注文字，关键词用空格分隔。输入框为空时显示提示文案。

账本内页按钮与跳转：

- 点击左上角返回：回到首页。
- 点击 `新建`：进入流水编辑（详情）页，模式为新建。
- 点击 `设置`：进入账本设置页。

## 流水列表页

流水列表页由账本内页点击 `查询` 后进入。该页面展示查询结果，不负责修改筛选规则；如果要改筛选规则，返回账本内页修改。

内容：

- 顶部 AppBar：左侧返回按钮，标题 `查询结果`，副标题或摘要显示当前筛选规则。
- 列表：按日期从新到旧排序，一天一个大标题，标题下缩进显示当天流水词条。
- 流水词条：显示二级分类、金额、收入/支出方向、币种、账户、时间、备注摘要。
- 加载状态：首次查询只加载一批；下拉到底再加载下一批，避免一次性加载过多数据。

按钮与行为：

- 点击日期大标题：折叠或展开当天流水词条。
- 点击流水词条：进入流水编辑（详情）页，模式为查看已有流水。
- 下拉到底：加载下一批查询结果。
- 点击返回：回到账本内页，保留上次查询规则。

## 流水编辑（详情）页

流水编辑（详情）页同时服务新建、查看和编辑。设计目标要求“编辑和新建是同一个界面”，因此不再拆分为独立的流水详情页和流水编辑页。查看已有流水时，同一页面以只读或可编辑状态展示；如果后续确实需要只读态，仍然在这个页面内切换，不新增独立详情页。

进入方式：

- 从账本内页点击 `新建`：进入新建模式。
- 从流水列表页点击流水词条：进入查看已有流水模式。
- 查看已有流水时点击编辑动作：在本页切换为编辑模式。

页面内容：

- 顶部 AppBar：标题根据模式显示 `记一笔`、`流水详情` 或 `编辑流水`；左侧返回或取消；右侧保存或编辑。
- 方向选择：收入、支出。
- 金额输入：金额计算器，最终金额用 float64 存储，显示保留两位小数。
- 币种选择：默认人民币；可选择常用外币；如果常用外币列表里没有需要的币种，可以跳转外币管理页添加。
- 分类选择：一级分类、二级分类。
- 账户选择：一级账户、二级账户；支出记录选择付款账户，收入记录选择收款账户。
- 时间选择：记账时间，默认当前时间。
- 备注输入：文字备注。
- 附件入口：图片附件，当前可以先留设计占位。

按钮与跳转：

- 点击保存：校验金额、分类、账户、币种和时间；保存成功后返回来源页。新建来源通常是账本内页，查看/编辑来源通常是流水列表页。
- 点击返回或取消：如果有未保存修改，弹出放弃修改确认；否则直接返回来源页。
- 点击删除：仅查看或编辑已有流水时显示；打开删除确认弹窗，确认后删除流水并返回来源页。
- 点击分类：打开分类选择页或弹窗。
- 点击账户：打开账户选择页或弹窗。
- 点击币种：打开币种选择页或弹窗。
- 点击编辑常用外币：进入外币管理页，返回后继续当前编辑流程。
- 点击时间：打开日期时间选择器。

## 分类选择页或弹窗

分类选择由流水编辑（详情）页触发。当前可先实现为弹窗，后续分类管理复杂后再拆为页面。

内容：

- 方向相关的分类列表：支出分类或收入分类。
- 一级分类列表。
- 选中一级分类后显示二级分类。
- 搜索框。
- `新建分类` 入口。

跳转与行为：

- 点击二级分类：返回流水编辑（详情）页并填入分类。
- 点击一级分类且没有二级分类：可直接选择一级分类。
- 点击 `新建分类`：进入分类管理页或打开新建分类弹窗。

分类查重规则：

- 一级分类不可重名。
- 同一个一级分类下的二级分类不可重名。
- 不同一级分类下的二级分类可以重名。
- 修改分类名称后，涉及条目自动显示新名称。
