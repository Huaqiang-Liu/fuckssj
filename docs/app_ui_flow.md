# App 界面与跳转说明

本文档描述 Flutter 记账 App 的界面结构、每个界面包含的内容、可打开的弹窗、按钮行为和跳转目标。

## 设计目标

这部分是总纲领，下面的表述如果有与这部分冲突的，以这里为准。

1. 导入和导出账本，多账本命名、管理、备注。一个账本是一个 `.sqlite` 文件。
2. 设置界面包含调节浅色/深色/跟随系统，以及默认字号基础上的字号加大选项。App 不单独设置全局主设置页；主题设置放在账本设置页里作为入口，但实际写入全局唯一持久化设置，所有账本共用同一个主题配置。
3. 记账，每条记账涉及：一级二级分类，收入和支出（金额默认人民币，可以修改成外币，可以在记账界面选择外币列表时跳转，或在当前账本的账本设置中编辑常用外币以显示在列表，后续可以现场查询汇率，==注意：原版随手记不支持外币记录，可能需要增补数据库格式，即在导入外部数据库文件后可能需要修改==），记账时间，账目备注（文字和图片），一级二级所属账户（现金、信用卡、金融账户（银行卡/股票/基金）、虚拟账户（支付宝/微信/白条/公交卡/饭卡）、负债账户（应付款项）、债券账户（应收款项）
4. 查询和编辑账目，【编辑和新建是同一个界面】。可以筛选日期，筛选分类（一级二级，币种，账户），筛选支出或收入（或者都有），筛选金额范围（都留空则全选，只空最低或最高金额则单方向查找即可）。可以搜索关键字（匹配备注文字，严格匹配，默认留空）
5. 自定义一级二级分类、一级二级所属账户、显示外币种类（设置时加上搜索）。分类、账户、外币用当前账本自己的 JSON 或等价配置结构维护（key-value+列表的模式很方便），不同账本之间互不共享。删除分类/账户前要提示相关账目也会被删除，并在同一操作弹窗内二次点击确认；删除常用外币只把币种移出当前账本常用列表，不删除全量币种定义。分类在当前账本内按层级查重：一级分类不可重名，同一个一级分类下的二级分类不可重名，不同一级分类下的二级分类可以重名；账户在当前账本内暂按不可重名处理。修改分类/账户名称后，涉及条目也自动修改。可以从记账/编辑界面跳转，也可以从当前账本的账本设置访问。
6. 所有金额用 float64 存储，但是显示时保留两位小数。其实只要计算汇率时保留 2 位小数（如 89.64 人民币≈13.19 美元），就不会有涉及更高精度的情况。

## 全局导航原则

App 的一级导航分为“首页”和“账本内页”。首页负责选择、创建、导入、导出和管理账本；账本内页负责查看和操作某一个已经打开的账本。进入某一账本后，不再显示三种创建账本入口，也不在右上角通过菜单切换账本；必须先返回首页，才能看到创建入口和账本选择列表。App 不提供独立的全局主设置页；分类、账户、外币均挂在当前账本设置下，主题设置也从账本设置进入但保存为全局唯一配置。

App 启动时读取本地持久化状态。如果存在上次打开的账本，并且对应账本文件仍存在，默认直接进入该账本的账本内页；如果没有上次账本、账本文件丢失、账本索引损坏或首次启动，则进入首页。账本内页左上角返回按钮回到首页；首页可以重新打开任意已有账本。如果默认打开账本时存在肉眼可见的自动跳转，而不是直接初始化到账本内页，则需要添加开屏界面。

账本文件和账本索引均由 App 管理。账本索引用于保存账本名称、文件路径、来源、创建时间、最近打开时间、备注、上次打开账本等元信息。账本名称由用户手动填写，不能为空，不能超过 40 个字符，不能包含 `\ / : * ? " < > |`，并且和现有账本大小写不敏感地查重。用户在首页可以修改账本名称。

分类、账户、外币配置由 App 自己维护，不长期依赖随手记原始表结构。工程内默认模板文件为 `app/assets/default_ledger_template.json`，当前默认分类种子来自本地 `recovered/mymoney.sqlite` 的 `t_category`；默认账户使用通用账户模板；默认常用币种包含 `CNY`、`USD`、`JPY`、`HKD`、`EUR`、`GBP`、`AUD`，并默认全部启用。每个账本打开、创建或导入时都会在 App 文档目录的 `ledgers/configs/<ledgerId>.json` 生成该账本自己的配置文件：空白账本从默认模板复制，SQLite/KBF 导入账本从各自数据库的 `t_category`、`t_account`/`t_account_group`、`t_currency` 自动识别生成，缺失的部分回退默认模板；如果导入数据库没有这些默认币种，App 仍会把默认常用币种合并进当前账本配置。

汇率缓存独立于单个账本，保存在 App 文档目录的 `ledgers/exchange_rates.json` 或等价本地文件中。该文件至少包含来源、基准币种、更新时间、刷新间隔和汇率表；联网时如果缓存超过 12 小时则尝试刷新，刷新失败时继续使用本地旧汇率，不阻断当前页面。后续如果改用银行牌价，需要明确来源和更新时间，因为不同银行牌价更新频率并不统一。

```text

  -> 账本管理动作：账本操作菜单 -> 重命名/备注/导出/删除

  -> 返回：首页
  -> 四个看板：今天/本周/本月/本年，只展示，不可点击
  -> 筛选/搜索块：查询 -> 流水列表页
  -> 新建流水：流水编辑（详情）页
  -> 设置：账本设置页

流水列表页
  -> 返回：账本内页
  -> 点击日期标题：折叠/展开当天流水
  -> 点击流水词条：流水编辑（详情）页
  -> 下拉到底：继续加载下一批查询结果

流水编辑（详情）页
  -> 返回/取消：返回来源页
  -> 保存：返回账本内页或流水列表页
  -> 删除：删除确认弹窗 -> 返回账本内页或流水列表页
  -> 选择分类：分类选择页或弹窗
  -> 选择账户：账户选择页或弹窗
  -> 选择币种：币种选择页或弹窗
  -> 编辑常用外币：当前账本的外币管理页

  -> 返回：账本内页
  -> 主题设置：浅色/深色/跟随系统、字号加大，写入全局唯一设置
  -> 分类管理：当前账本的分类管理页
  -> 账户管理：当前账本的账户管理页
  -> 外币管理：当前账本的外币管理页
```

## 首页

首页是账本选择和账本创建入口，不展示某个账本的流水列表。首页顶部标题为 `账本`。如果没有任何账本，页面主体显示空状态文案和三个创建入口；如果已有账本，页面主体先显示账本列表，再显示创建入口。

首页内容：

- 顶部 AppBar：标题 `账本`。首页不提供独立主设置入口；主题设置从某个账本的账本设置页进入。
- 已有账本列表：每个条目显示账本名称、来源类型、创建时间、最近打开时间、可选备注、文件状态。
- 创建入口区：三个按钮分别为 `创建空白账本`、`从 SQLite 创建`、`从随手记本地备份导出的 KBF 文件创建`。
- 状态提示区：导入中、创建中、导入失败、账本文件丢失等错误或进度信息。
- 底部信息区：显示当前版本号和开源协议，当前为 `开源协议：MIT`。

首页按钮与跳转：

- 点击已有账本条目：设置该账本为上次打开账本，打开账本内页。
- 点击 `创建空白账本`：打开命名账本弹窗；命名成功后创建空白 SQLite 账本，写入 App schema 增广表，注册账本索引，进入账本内页。
- 点击 `从 SQLite 创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.sqlite`、`.sqlite3`、`.db`、`.db3`；选择成功后复制文件到 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。
- 点击 `从随手记本地备份导出的 KBF 文件创建`：打开命名账本弹窗；命名成功后打开系统文件选择器，允许选择 `.kbf`；选择成功后在 Dart 侧解析 ZIP，读取 `mymoney.sqlite`，恢复 SQLite 头，校验数据库，写入 App 管理目录，执行 schema 迁移和增广，注册账本索引，进入账本内页。
首页账本管理动作：

- 长按账本条目或点击条目右侧更多按钮：打开账本操作菜单。
- 账本操作菜单包含 `重命名`、`编辑备注`、`导出账本`、`删除账本`。
- `重命名` 使用命名账本弹窗的同一套校验规则。
- `编辑备注` 打开账本备注弹窗，弹窗内是多行输入框，底部按钮为 `取消`、`保存`；备注可以为空。
- `导出账本` 打开系统保存位置选择器；默认文件名包含账本名称和当前日期时间（年月日时分秒），扩展名为 `.sqlite`。
- `删除账本` 必须弹出确认弹窗，标题为 `确认删除账本"<账本名称>"？`，底部按钮为 `取消`、红色醒目的 `确认删除`，确认后删除 App 管理目录中的账本文件、配置文件和索引记录。

## 命名账本弹窗

命名账本弹窗由首页的三个创建入口和账本重命名动作触发。弹窗不负责实际创建或导入文件，只负责收集和校验账本名称。

弹窗内容：

- 标题：新建时为 `命名账本`，重命名时为 `重命名账本`。
- 输入框：标签 `账本名称`，最大长度 40。
- 错误提示：显示名称为空、名称过长、包含非法字符、名称已存在等错误。
- 按钮：`取消`、`继续` 或 `保存`。

弹窗行为：

- 点击 `取消`：关闭弹窗，停留来源页，不继续文件选择或创建账本。
- 点击 `继续` 或 `保存`：校验账本名称；校验失败时留在弹窗并显示错误；校验成功时关闭弹窗，把名称返回给来源流程。
- 输入法完成键：等同点击确认按钮。

## 文件选择器

文件选择器由首页的导入流程触发，不是 App 自绘页面。文件选择器关闭后，回到首页对应流程继续处理。

SQLite 文件选择：

- 允许扩展名：`.sqlite`、`.sqlite3`、`.db`、`.db3`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：复制到 App 管理目录，不长期依赖原文件路径。

KBF 文件选择：

- 允许扩展名：`.kbf`。
- 用户取消选择：回到首页，不创建账本。
- 选择文件后：Dart 侧执行和 Python 脚本等价的恢复逻辑；Python 脚本仍保留给桌面手动恢复使用。

## 账本内页

账本内页只展示当前打开账本的数据和操作入口。账本内页不显示三种创建账本入口，也不在右上角切换账本；账本切换必须返回首页完成。

账本内页布局：

- 顶部 AppBar：左侧返回箭头，标题显示当前账本名称。
- 顶部看板区：四个看板分别为 `今天`、`本周`、`本月`、`本年`，只展示，不可点击。
- 中部筛选/搜索块：账户、开始时间、结束时间、币种、分类、金额范围、收入/支出、查询备注、查询按钮、重置筛选规则按钮。
- 底部操作区：底部中间放 `新建` 按钮，底部右侧放 `设置` 按钮。

四个看板：

- `今天`：显示标题、今日总收入、今日总支出，不显示最近流水分类。
- `本周`：显示标题、本周总收入、本周总支出，不显示最近流水分类。
- `本月`：显示标题、本月总收入、本月总支出，不显示最近流水分类。
- `本年`：显示标题、本年总收入、本年总支出，不显示最近流水分类。
- 收入金额显示红色，支出金额显示绿色。
- 如果流水中有外币，看板金额需要按当前汇率折算成人民币后汇总；后续需要定期刷新汇率并重新计算。

筛选/搜索块：

- 点击 `查询`：按当前筛选规则进入流水列表页。查询前检查账户、币种、分类、收入/支出不能全部留空；金额范围如果最小值大于最大值，弹窗提示并留在账本内页。
- 点击 `重置筛选规则`：重置为默认规则。默认规则是账户全选、时间全选、币种全选、分类全选、收入/支出全选、金额范围为空、查询备注为空。
- 每个账本保存上次查询的筛选规则作为账本元数据；再次打开账本时恢复该规则。

筛选字段：

- 账户：点击后打开居中的账户列表复选框弹窗。账户按一级/二级层级展示，用缩进表示。选中一级账户则其下二级账户全选；取消任意二级账户后，一级账户进入未全选状态。弹窗内有全选按钮，默认全选。选择后点击确定关闭弹窗。
- 开始时间和结束时间：点击后打开居中的日历弹窗。可以前后切换月份和年份，点击日期选中，点击确定关闭。时间全选默认开启；全选开启时，打开日历仍定位在当前日期所在月份，不定位到 1970 年。选择开始或结束日期后，全选自动取消。
- 币种：点击后打开居中的常用币种复选框弹窗。币种来自当前账本设置里的常用外币列表，默认含人民币。弹窗内有全选按钮，默认全选。取消任意币种后，全选自动取消。
- 分类：点击后打开居中的分类列表复选框弹窗。分类按一级/二级层级展示，用缩进表示。选中一级分类则其下二级分类全选；取消任意二级分类后，一级分类进入未全选状态。弹窗内有全选按钮，默认全选。
- 金额范围：两个输入框，分别为最低金额和最高金额。都为空表示全范围；只填最低表示大于等于该金额；只填最高表示小于等于该金额；都填时必须保证最低金额不大于最高金额。
- 收入/支出：两个紧凑筛选 chip 直接放在筛选块里，不打开弹窗，默认全选；布局上放在分类筛选右侧，并与账户、币种、分类等筛选 chip 等高对齐。
- 查询备注：文本输入框，默认留空，严格匹配备注文字，关键词用空格分隔。输入框为空时显示提示文案。

账本内页按钮与跳转：

- 点击左上角返回：回到首页。
- 点击 `新建`：进入流水编辑（详情）页，模式为新建。
- 点击 `设置`：进入账本设置页。

## 流水列表页

流水列表页由账本内页点击 `查询` 后进入。该页面展示查询结果，不负责修改筛选规则；如果要改筛选规则，返回账本内页修改。

内容：

- 顶部 AppBar：左侧返回按钮，标题 `查询结果`，副标题或摘要显示当前筛选规则。
- 列表：按日期从新到旧排序，一天一个大标题，标题下缩进显示当天流水词条。
- 流水词条：显示二级分类、金额、收入/支出方向、币种、账户、时间、备注摘要。
- 加载状态：首次查询只加载一批；下拉到底再加载下一批，避免一次性加载过多数据。

按钮与行为：

- 点击日期大标题：折叠或展开当天流水词条。
- 点击流水词条：进入流水编辑（详情）页，模式为查看已有流水。
- 下拉到底：如果仍有下一批结果，自动加载下一批；如果全部加载完成，继续划到底部不再触发请求。
- 点击返回：回到账本内页，保留上次查询规则。

## 流水编辑（详情）页

流水编辑（详情）页同时服务新建、查看和编辑。设计目标要求“编辑和新建是同一个界面”，因此不再拆分为独立的流水详情页和流水编辑页。查看已有流水时，同一页面以只读或可编辑状态展示；如果后续确实需要只读态，仍然在这个页面内切换，不新增独立详情页。

进入方式：

- 从账本内页点击 `新建`：进入新建模式。
- 从流水列表页点击流水词条：进入查看已有流水模式。
- 查看已有流水时点击编辑动作：在本页切换为编辑模式。

页面内容：

- 顶部 AppBar：标题根据模式显示 `记一笔`、`流水详情` 或 `编辑流水`；左侧返回或取消；右侧保存或编辑。
- 方向选择：收入、支出。
- 金额输入：最终金额用 float64 存储，显示保留两位小数；金额输入框右侧显示当前币种按钮，按钮包含币种代码和旗帜或地区标识。
- 币种选择：点击金额输入框右侧币种按钮弹出当前账本常用币种列表，默认人民币；如果常用外币列表里没有需要的币种，可以跳转当前账本的外币管理页添加。
- 分类选择：一级分类、二级分类。
- 账户选择：一级账户、二级账户；支出记录选择付款账户，收入记录选择收款账户。
- 时间选择：记账时间，默认当前时间。
- 备注输入：文字备注。
- 附件入口：图片附件，当前可以先留设计占位。

按钮与跳转：

- 点击保存：校验金额、分类、账户、币种和时间；保存成功后返回来源页。新建来源通常是账本内页，查看/编辑来源通常是流水列表页。
- 点击返回或取消：如果有未保存修改，弹出放弃修改确认；否则直接返回来源页。
- 点击删除：仅查看或编辑已有流水时显示；打开删除确认弹窗，确认后删除流水并返回来源页。
- 点击分类：打开分类选择页或弹窗。
- 点击账户：打开账户选择页或弹窗。
- 点击币种：打开币种选择页或弹窗。
- 点击编辑常用外币：进入当前账本的外币管理页，返回后继续当前编辑流程。
- 点击时间：打开日期时间选择器。

## 分类选择页或弹窗

分类选择由流水编辑（详情）页触发。当前可先实现为弹窗，后续分类管理复杂后再拆为页面。

内容：

- 方向相关的分类列表：支出分类或收入分类。
- 分类按一级分组展示；一级分类显示为分组标题，二级分类用小框横向换行展示，避免每条都重复显示 `一级分类/二级分类`。
- 顶部显示 `最近使用` 分组；每个账本分别保存收入、支出最近使用分类各最多 8 个，重复使用会挪到最前面。
- 搜索框。
- `新建分类` 入口。

跳转与行为：

- 点击二级分类：返回流水编辑（详情）页并填入分类。
- 点击一级分类且没有二级分类：可直接选择一级分类。
- 点击 `新建分类`：进入分类管理页或打开新建分类弹窗。

分类查重规则：

- 一级分类不可重名。
- 同一个一级分类下的二级分类不可重名。
- 不同一级分类下的二级分类可以重名。
- 修改分类名称后，涉及条目自动显示新名称。
- 删除分类前必须提示会删除其下流水；当前操作弹窗内第一次点击删除进入二次确认状态，删除按钮变为“相关账目也会被删除”，第二次点击才真正删除。
- 保存流水时，根分类写入随手记兼容的根父级标记 `-1`，避免导入库中 `parentCategoryPOID` 非空约束导致保存失败。

## 账户选择页或弹窗

- 搜索框。
- `新建账户` 入口。

跳转与行为：

- 点击二级账户：返回流水编辑（详情）页并填入账户。
- 点击一级账户且没有二级账户：可直接选择一级账户。
- 点击 `新建账户`：进入账户管理页或打开新建账户弹窗。
- 修改账户名称后，涉及条目自动显示新名称。
- 删除账户前必须提示会删除其下流水；当前操作弹窗内第一次点击删除进入二次确认状态，删除按钮变为“相关账目也会被删除”，第二次点击才真正删除。

## 币种选择页或弹窗

币种选择由流水编辑（详情）页触发。常用币种列表在当前账本的账本设置中维护，不同账本可以有不同的常用币种列表。默认常用币种为 `CNY`、`USD`、`JPY`、`HKD`、`EUR`、`GBP`、`AUD`，默认全部可选；这不代表 App 只支持这 7 种，其它币种后续可在外币管理页搜索并启用。

内容：

- 常用币种列表，默认包含 `CNY`、`USD`、`JPY`、`HKD`、`EUR`、`GBP`、`AUD`。
- 搜索框。
- 汇率显示，来自本地汇率缓存；缓存过期且联网可用时再刷新。
- `管理常用外币` 入口。

跳转与行为：

- 点击币种：返回流水编辑（详情）页并填入币种。
- 点击 `管理常用外币`：进入当前账本的外币管理页。
- 常用外币删除只把该币种移出当前账本常用列表，不删除全量币种定义；涉及既有流水的处理在后续流水编辑与统计规则中补齐。

## 分类管理页

分类管理页维护当前账本的一级/二级分类数据。分类数据使用当前账本自己的 JSON 或等价配置结构维护，具体结构后续在数据设计阶段确定；不同账本之间分类互不共享。

内容：

- 顶部方向切换：支出分类、收入分类。
- 分类列表：一级分类纵向排列；每个一级分类下的二级分类用小框横向换行排列。
- 搜索框。
- 新建一级分类、新建二级分类、重命名、删除；新增二级词条按钮需要和普通二级词条小框颜色区分。

行为：

- 新建或重命名时执行分类查重规则，并限制分类名称长度；一级分类和二级分类都不应允许过长名称破坏界面布局。
- 长按一级分类词条：屏幕中间打开操作弹窗，弹窗标题处直接显示可编辑的名称输入框，底部按钮从左到右为 `取消`、`删除`、`确定`，其中 `删除` 使用红色强调；第一次点击删除后，弹窗内删除区域变为浅红背景、红色加粗文案 `相关账目也会被删除`，再次点击才真正删除；点击弹窗外区域或系统返回键视作取消。
- 长按二级分类小框：屏幕中间打开同样的操作弹窗，弹窗标题处直接显示可编辑的名称输入框，底部按钮从左到右为 `取消`、`删除`、`确定`，其中 `删除` 使用红色强调；第一次点击删除后，弹窗内删除区域变为浅红背景、红色加粗文案 `相关账目也会被删除`，再次点击才真正删除；点击弹窗外区域或系统返回键视作取消。
- 删除分类会更新当前账本配置；如果该分类来自随手记导入的 `ssj_` 节点，同时删除 App 管理的 SQLite 副本中该分类及其子分类下的流水和分类记录。
- 修改分类名称后，当前账本配置与随手记 SQLite 副本中的 `t_category.name` 同步更新，历史流水查询自动显示新名称。
- 从流水编辑（详情）页跳转进入时，完成新增或修改后可以返回编辑页继续填写；从账本设置页进入时，返回当前账本的账本设置页。

- 从流水编辑（详情）页跳转进入时，完成新增或修改后可以返回编辑页继续填写；从账本设置页进入时，返回当前账本的账本设置页。

## 外币管理页

外币管理页维护当前账本的常用外币列表。外币数据使用当前账本自己的 JSON 或等价配置结构维护，具体结构后续在数据设计阶段确定；不同账本之间常用外币互不共享。

内容：

- 常用币种列表。
- 右上角添加入口。
- 左滑删除操作。
- 汇率显示，来自本地汇率缓存；缓存过期且联网可用时自动刷新。

行为：

- 人民币默认存在，原则上不允许删除。
- 默认常用币种为 `CNY`、`USD`、`JPY`、`HKD`、`EUR`、`GBP`、`AUD`，并默认全部启用；其它币种通过搜索添加或勾选启用。
- 汇率保存在本地汇率缓存文件中，离线时使用最近一次缓存值；联网且缓存超过 12 小时时尝试刷新，刷新失败不阻断记账。
- 外币管理页只显示当前常用外币，人民币排在最顶上，每个外币词条右侧显示当前汇率。
- 常用外币词条左滑后右侧显示红色删除按钮，点击删除会把该币种移出当前账本常用外币列表。
- 右上角 `+` 进入添加常用外币页。
- 外币管理不提供币种名称编辑；需要新增其它币种时通过搜索添加或勾选启用。
- 从流水编辑（详情）页跳转进入时，完成新增或修改后可以返回编辑页继续填写；从账本设置页进入时，返回当前账本的账本设置页。

## 添加常用外币页

添加常用外币页维护当前账本的常用外币勾选状态，不修改全量外币列表本身。

内容：

- 顶部搜索栏：关键词匹配货币中文名称和货币代码；右上角提供 `全选` 选择框，可一次性勾选全部支持币种，也可取消勾选以批量移除非人民币常用币种。
- 货币词条列表：搜索栏为空时显示全部货币，输入关键词时显示匹配项；每个词条显示货币名称、代码、当前汇率和选择框。

行为：

- 勾选货币：把该币种加入当前账本常用外币列表。
- 取消勾选货币：把该币种移出当前账本常用外币列表；人民币保持启用。
- 勾选 `全选`：把添加页中全部支持币种加入当前账本常用外币列表；取消勾选 `全选`：批量移除非人民币常用币种，人民币保持启用。
- 勾选或取消后，词条仍保持在当前位置，不改变排序，不从当前列表消失。
- 系统返回或顶部返回：保存当前账本常用外币配置并返回外币管理页；页面不提供额外的完成按钮。

## 账本设置页

账本设置页是当前账本的设置入口，不负责切换账本。除主题设置外，本页所有配置都只作用于当前账本；主题设置只是从这里进入，实际保存为全局唯一 App 设置。

内容：

- 账本名称。
- 账本备注。
- 账本文件路径或存储位置说明。
- 来源类型：空白账本、SQLite 导入、KBF 导入。
- 主题设置：浅色、深色、跟随系统、字号加大。该项入口放在账本设置页，但实际保存为全局唯一 App 设置，对所有账本生效。
- 当前账本分类管理入口。
- 当前账本账户管理入口。
- 当前账本外币管理入口。

按钮与跳转：

- 点击保存：保存账本名称和备注，返回账本内页。
- 点击主题设置：切换主题和字号加大选项并保存到全局 App 设置，所有账本共用这个主题配置。
- 点击分类管理：进入当前账本的分类管理页。
- 点击账户管理：进入当前账本的账户管理页。
- 点击外币管理：进入当前账本的外币管理页。
