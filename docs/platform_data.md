# 平台与数据说明

本文说明当前版本在不同平台上的使用边界，以及账本数据在 App 内的保存方式。

## 平台

fuckssj 是 Flutter App。当前 Android APK 可直接安装使用；iOS 使用同一套账本、查询、看板和配置规则，正式安装方式以发布说明为准。

App 不要求用户提供固定文件夹路径。导入、导出和保存都通过系统文件能力或 App 自己的本地管理目录完成，因此不同平台上的具体目录会由系统决定。

## 本地数据

- 每个账本会被复制到 App 管理目录中保存。
- App 首页展示的是已经注册到 App 内的账本，不直接扫描手机上的所有文件。
- 账本名称、备注、来源、最近打开时间等信息由 App 单独保存。
- 分类、账户和常用币种属于当前账本，不同账本之间互不共享。
- 主题和字号设置属于整个 App，对所有账本生效。

## 导入与导出

支持从随手记 `.kbf` 本地备份创建账本，也支持导入 `.sqlite`、`.sqlite3`、`.db`、`.db3` 文件。

导入完成后，App 使用自己的副本；原始文件被移动、删除或重命名，不会影响已经导入的账本。

导出账本时会生成明文 SQLite 文件。该文件包含完整流水和账本配置相关数据，请按普通账本备份妥善保存。

## iOS 文件访问

iOS 使用系统文件选择器和 App 沙盒。能导入或导出到哪些位置，取决于系统文件 App、云盘 App 和用户授权状态。

如果某个文件位置不能被选择或写入，通常是系统权限限制，不代表账本数据格式不兼容。可以先把文件移动到系统“文件”App 中可访问的位置，再重新导入或导出。

## 汇率缓存

看板和汇总中的外币金额会按本地汇率缓存折算成人民币。缓存可用时优先使用缓存；联网刷新失败不会阻断记账、查询或打开账本。

没有外币流水时，人民币流水不需要进行外币折算。

## 数据删除

删除账本会删除 App 管理目录中的账本文件、配置文件和索引记录。

删除分类或账户时，如果该分类或账户已经被流水使用，相关流水会一起删除。删除前请确认已经导出或备份需要保留的数据。
